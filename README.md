# 吉他指板练习室

帮助吉他初学者对照指板位置、音名、唱名与声音的轻量练习工具。由个人练习需求出发，使用 AI 辅助实现。

## 功能

- 保留原始简洁风格，支持系统明暗主题。
- 默认21品，可切换22品、24品；标准调弦 E A D G B E。
- C、G、A大调切换，音名与首调唱名切换。
- 点击音位发声，并查看其他相同音高的位置。
- 9个基础和弦、12种常见变化和弦，支持齐奏与分解试听。
- 音量调节和停止播放。
- 无需登录或联网；声音由浏览器合成，不使用外部录音采样。

## 本地使用

使用 Safari、Chrome 或 Edge 打开 `index.html`。首次发声需要点击一个音位或试听按钮。设置保存在当前浏览器，若浏览器不允许本地存储，仍可使用，但设置可能不会保存。
